# Gymholic_2

A fitness management and tracking application designed to help users reach their health and wellness goals efficiently.

## 🚀 Overview
Gymholic_2 is a full-stack application built to track workouts, monitor fitness progress, and manage training routines. Designed for performance and ease of use, this project leverages modern web technologies to provide a seamless user experience.

## 🛠 Tech Stack
* **Frontend:** React, TypeScript, Tailwind CSS, shadcn-ui
* **Build Tool:** Vite
* **Language:** TypeScript
